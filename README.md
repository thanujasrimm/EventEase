
# ✨ EventEase — Event Discovery & Ticket Reservation

Discover exciting events, explore experiences, and find your next favourite event with EventEase.

## 📌 About the Project

EventEase is a web-based event discovery and ticket reservation project designed to provide users with a simple and attractive interface for exploring events.

This project is being developed as a learning project, starting with the frontend and gradually expanding to a complete event reservation system.

## ✨ Features

- 🎨 Modern dark-purple and lavender user interface
- 🎫 Event cards with dates, locations, and ticket prices
- 🔎 Search events by name or location
- 🗂️ Filter events by category
- ❤️ Interactive favourite buttons
- 🪄 Ticket selection popup
- 📱 Responsive layout for desktop and mobile
- ✨ Smooth animations and hover effects

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts
- Unsplash images

## 🚀 How to Run the Project

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser.

Alternatively, install the Live Server extension in VS Code, open `index.html`, and click **Go Live**.

## 🖥️ Current Project Status

The current version is a frontend prototype.

Event browsing, category filtering, search, favourite buttons, and the ticket selection popup are implemented.

Real user authentication, database integration, temporary ticket reservations, payment simulation, and organizer analytics are planned for future development.

## 🔮 Future Enhancements

- User authentication and role-based access control
- Admin, Organizer, and Attendee dashboards
